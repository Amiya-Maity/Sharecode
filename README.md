# Sharecoder
This extension eases to download and upload the small texts from a online text sharing platform Sharecode (https://sharecode.hackend.in). 
## Commands
- sharecoder.dnldselectcodes
- sharecoder.dnldsefilecodes
- sharecoder.upldselectcodes
- sharecoder.upldsefilecodes
## How to run
### Download using `right click`
- Right click on the editor
- Click on the `Download from Sharecode` command

### Upload using `right click`
- Right click on the editor
- Click on the `Upload to Sharecode` command

## Steps to use downloader(using file)
- Enter the `id`, where you put the text and click `enter`. e.g from [`sharecode.hackend.in/any_id`](https://share.hackend.in/any_id) give `any_id`
- Search the file name where to you want save and select. Then confirm the accepting code or the current code.

## Steps to use downloader(using clipboard)
- Enter the `id`, where you put the text and click `enter`. e.g from [`sharecode.hackend.in/any_id`](https://share.hackend.in/any_id) give `any_id`
- Code is saved to clipboard

## Steps to use uploader(using file)
- Enter the `id`, where you want to put the text and click `enter`. e.g from [`sharecode.hackend.in/any_id`](https://share.hackend.in/any_id) give `any_id`
- Search th file name using the search bar provided and select the file whose content you want to upload

## Steps to use uploader(selecting text)
- Firstly, Select text to be shared
- Right click on the text
- Enter the `id`, where you want to put the text and click `enter`. e.g from [`sharecode.hackend.in/any_id`](https://share.hackend.in/any_id) give `any_id`

## Steps to cancel an operation
- for the `id` input press `escape` button
